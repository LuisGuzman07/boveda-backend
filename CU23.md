# CU-23 Safe Compliance Report Export

## Scope

`POST /api/v1/audit/reports` creates a persisted aggregate-only compliance report.
`GET /api/v1/audit/reports` lists reports and `GET /api/v1/audit/reports/{report_id}/download?formato=json|csv` downloads one.
All three endpoints require `audit:export`; `audit:read` remains limited to the existing audit read endpoints.

Reports contain only the selected period and filters, event counts, audit-chain result, governance-change count, replica status counts, and anomaly run/finding counts with a run reference. They exclude event rows, audit details, identities, contact data, IP addresses, user agents, credentials, encryption material, object identifiers, ciphertext metadata, and Emergency Kit data. CSV output neutralizes formula-leading cells.

The historical `/api/v1/audit/export` endpoint now returns `410 Gone` and has no raw export implementation.

Generation and download are separately written to the immutable audit chain with the report ID and normalized filters only.

## Client Scope

The web audit page supports period, event-type/outcome filters, JSON/CSV generation, loading, error, empty, list, and download states. Mobile has no CU-23 UI; the server API is client-neutral and may be consumed by a future mobile implementation.
